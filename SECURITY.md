# Security policy

## Supported project

Security fixes are accepted for the current default branch.

## Reporting a concern

Please do not publish passwords, tokens, private keys, personal data, or exploit details in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security** tab to submit a private report. If it is not enabled, contact the repository maintainer through GitHub before sharing sensitive technical details.

## Scope

Prompt Vault is a static website. It does not operate a user database or server-side account system. Relevant reports may include unsafe HTML rendering, malicious resource content, dependency or workflow risks, and privacy problems.

Please include the affected page or file, a concise description, and steps to reproduce that do not expose real secrets or other people's data.
