QUICK GUIDE

Make the library work for you.

Find a useful starting point, adapt it to your task, and keep the resources you use.

1. Find a resource

Search titles, descriptions, categories, tags, and resource text. Narrow the results with the type, category, collection, difficulty, and tag filters. Use Clear filters to start over.

2. Personalise a prompt

Open a resource card. If it contains fill-in fields, enter your own task details. The preview updates as you type. Copy or download the completed version when it is ready. Empty fields remain as placeholders.

3. Save useful resources

Select the star on a card to add or remove a favourite. Turn on Favourites only to see saved items. Favourites are stored in this browser, not in an online account.

4. Back up or restore favourites

Choose Export favourites to save a JSON backup. On another browser, choose Import favourites and select that backup. Only IDs that still exist in the current catalogue are restored.

5. Share and download

Copy view link to share the current filters. Inside a resource, Copy resource link shares that item directly. Download .txt saves the current personalised text as a plain-text file.

6. Use the library offline

After the site has loaded once while online, supported browsers can keep the core library files in their cache. The site shows an Offline mode indicator when the browser reports no network connection. External fonts may fall back to system fonts.

7. Suggest an improvement

Use the resource suggestion form to propose original content, or the bug report form to report a problem. Read the content guidelines before submitting.
