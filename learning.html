Glossary

Context
Background information the model needs to understand the task.
Constraint
A boundary or requirement that shapes the response.
Placeholder
A clearly marked value to replace with task-specific information.
Output format
The requested structure, such as prose, a table, JSON, or a checklist.
Iteration
Improving a prompt or result through deliberate revision.
Evaluation
Checking an output against explicit criteria rather than relying on confidence or fluency.

Contributor learning path

  1. Write original material; do not copy third-party prompt collections.
  2. Record sources, assumptions, model tests, and known limitations honestly.
  3. Check safety, privacy, accessibility, and factual claims.
  4. Use the contribution template and respond constructively to review feedback.
