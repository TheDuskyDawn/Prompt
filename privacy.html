PRIVACY

Simple by design.

Prompt Vault is a static website. It does not require an account.

What stays on your device

  • Your favourites are stored in this browser's local storage.
  • Your light or dark theme preference is stored in this browser's local storage.
  • When you import a favourites backup, it is read locally in your browser. It is not uploaded.
  • The service worker stores site files in the browser cache so the library can work offline.

What the site sends

  • There are no user accounts, advertising trackers, or analytics scripts in this project.
  • The stylesheet requests fonts from Google Fonts. Your browser contacts Google's font services to retrieve them; system fonts are used if they are unavailable.
  • Copy actions use the browser clipboard only after you press a copy button.
  • Links to GitHub Issues and the repository open GitHub, which is governed by GitHub's own privacy practices.

Your choices

You can clear this site's local storage and cached files through your browser settings. You can also use the site without saving favourites or changing the theme.

Changes

This notice may be updated when the site adds new features or external services. The project repository is the source of truth for current implementation details.
